# Java Learning Notes

In diesem Repository dokumentiere ich meinen Lernfortschritt in der Programmiersprache Java.

Die Inhalte entstehen während meiner Umschulung zum Fachinformatiker für Anwendungsentwicklung und werden nach und nach durch eigene Erklärungen, Beispiele und Übungen ergänzt.

## 📚 Themen

* Variablen und Datentypen
* Konsolenausgaben
* Bedingungen mit `if` und `else`
* Schleifen
* Methoden
* Klassen und Objekte
* Konstruktoren
* Vererbung und Interfaces
* Collections
* Fehlerbehandlung

## 🎯 Ziel

Mein Ziel ist es, die grundlegenden Java-Konzepte nicht nur auswendig zu lernen, sondern sie verständlich erklären und in eigenen Projekten anwenden zu können.
